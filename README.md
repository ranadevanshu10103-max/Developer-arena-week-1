# Python Basics - Personal Introduction Program

## Project Overview

This project is a simple Python program created as part of Week 1 of The Developers Arena internship.

The program asks the user for their name, age, and favorite hobby, and then displays a friendly personalized welcome message.

## Features

- Takes user input using `input()`
- Stores information in variables
- Uses f-strings for formatted output
- Displays a personalized welcome message
- Uses basic Python concepts

## Technologies Used

- Python

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
